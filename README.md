# Contact-Card-QR-Android
Your contact card, one scan away. Contact Card QR makes it quick and easy to share your details with anyone.

## Version bump
To bump the version, update the versionCode value and the versionName value in app/build.gradle.kts
The versionCode value is an integer internal to Android and the IDE, just increment that every version bump.
The versionName value is a string that everyone sees. That should be the public version, like "0.1.1" or "1.0.0".


## Building and running the app
To run the app for testing, load the project folder in the Android IDE and click the 'Run app' button.


## Generating a signed APK for release
Go to the following URL for instructions:
https://developer.android.com/studio/publish/app-signing#sign-apk
